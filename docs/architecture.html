WriterLoop AI - Optimized Docker Architecture

Production-ready architecture optimized for lower image size, faster builds, lower memory, and simpler contributor onboarding, while keeping Qdrant as a default core dependency.

Next.js Standalone Multi-Stage Docker Qdrant Default Lite + Full Profiles BackgroundTasks or Celery

Runtime Profiles

Profile Services Container Count Use Case
Default frontend, backend, postgres, qdrant 4 Daily development and local production-like testing with semantic search enabled.
Full Default + redis, worker 6 Scaled queue execution with Celery.

Ports: 3000 frontend, 8000 backend, 5432 postgres, 6333 qdrant, plus 6379 redis in full mode.

Task Execution Modes

TASK_EXECUTION_MODE=background (default)
  -> FastAPI BackgroundTasks
  -> no Redis/Celery required

TASK_EXECUTION_MODE=inline
  -> runs in API process

TASK_EXECUTION_MODE=celery
  -> enqueue to Celery worker
  -> requires redis + worker (full profile)

Optimizations Applied

  • Frontend image reduction: Next.js standalone output with minimal runtime copy only (.next/standalone, static, public).
  • Backend Docker optimization: Python multi-stage build with virtualenv copied into runtime image.
  • Build context minimization: aggressive .dockerignore excluding docs/tests/git caches/node_modules/build outputs.
  • Qdrant always available: removed from optional profile and kept in default mode for semantic features.
  • Startup reliability: postgres healthcheck and dependency conditions in compose.
  • Qdrant memory optimization: on-disk payload mode enabled in compose; collection creation tuned for indexing threshold.
  • Contributor experience: simple default command, explicit full mode, and dedicated Docker cleanup script.

Docker Compose (Current)

services:
  frontend:
    image: writerloop-ai-frontend:dev
    build:
      context: .
      dockerfile: docker/frontend.Dockerfile
    restart: unless-stopped
    environment:
      NEXT_PUBLIC_API_BASE_URL: ${NEXT_PUBLIC_API_BASE_URL:-http://localhost:8000/api/v1}
    depends_on:
      - backend
    ports:
      - "3000:3000"

  backend:
    image: writerloop-ai-backend:dev
    build:
      context: .
      dockerfile: docker/backend.Dockerfile
    restart: unless-stopped
    env_file:
      - .env
    environment:
      TASK_EXECUTION_MODE: ${TASK_EXECUTION_MODE:-background}
    depends_on:
      postgres:
        condition: service_healthy
      qdrant:
        condition: service_started
    ports:
      - "8000:8000"

  worker:
    image: writerloop-ai-backend:dev
    profiles: [full]
    restart: unless-stopped
    env_file: [.env]
    environment:
      TASK_EXECUTION_MODE: celery
    depends_on:
      backend:
        condition: service_started
      redis:
        condition: service_healthy
    command: celery -A app.worker.celery_app.celery_app worker --loglevel=info

  postgres:
    image: postgres:16-alpine
    restart: unless-stopped
    environment:
      POSTGRES_DB: ${POSTGRES_DB:-writerloop}
      POSTGRES_USER: ${POSTGRES_USER:-writerloop}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-writerloop}
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER:-writerloop} -d ${POSTGRES_DB:-writerloop}"]
      interval: 10s
      timeout: 5s
      retries: 6

  redis:
    image: redis:7-alpine
    profiles: [full]
    restart: unless-stopped
    ports:
      - "6379:6379"
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 6

  qdrant:
    image: qdrant/qdrant:v1.13.2
    restart: unless-stopped
    environment:
      QDRANT__STORAGE__ON_DISK_PAYLOAD: "true"
    ports:
      - "6333:6333"
    volumes:
      - qdrant_data:/qdrant/storage

volumes:
  postgres_data:
  qdrant_data:

Docker and Maintenance Scripts

scripts/dev-up-detached.sh

cp -n .env.example .env || true
docker compose up --build -d

scripts/dev-up-full-detached.sh

cp -n .env.example .env || true
docker compose --profile full up --build -d

scripts/dev-down.sh

docker compose down --remove-orphans

scripts/dev-reset.sh

docker compose down --volumes --remove-orphans --rmi local

scripts/docker-clean.sh

docker builder prune -af
docker image prune -af

scripts/dev-prune-space.sh

bash scripts/docker-clean.sh
